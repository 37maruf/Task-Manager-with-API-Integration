# Task Manager with API Integration

Vanilla JavaScript project (no frameworks, no libraries).

## How to run
Open `index.html` in your browser. That's it.

## Structure
- `index.html` - page layout
- `style.css` - styling
- `js/async-practice.js` - Task 1 (event loop, setTimeout, setInterval, callback, Promise, async/await)
- `js/todo-app.js` - Task 2 (local todo app)
- `js/api-todos.js` - Task 3 & 4 (fetch API, filters)

## Bonus features done
- Search todos by title
- Refresh button for API data
- Empty tasks are blocked
- API todos and local todos are shown separately
